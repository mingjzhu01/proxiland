What the code already tells us: the brand (#4A3B31 / #F5EFE6) only appears on the splash and a few event buttons. Everything else is generic #111 black pills, #eee hairlines and an unrelated #3b5bdb blue doing all the "AI reasoning" work at 12–13px. Sections on the event screen are 16px bold labels with no separation.
